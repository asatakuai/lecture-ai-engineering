# 第3回 解答

## 演習

- 第1回（素のLLM）とエージェントの回答の違い：
  第1回の素のLLMは講座を知らず、「3レベル」について講座と違う説明が混ざった。
  エージェントは用語集を検索して、講座どおり（基礎・実装・発展）に答え、
  最後に「関連する回：第1回」まで付けた。
- `--trace` で見えたツール呼び出し（ツール名と引数）：
  「LoRAとQLoRAの違いは？」では、search_glossary({'query': 'LoRA'}) と
  search_glossary({'query': 'QLoRA'}) の2回。
  「第2回の内容から確認問題を1問出して」では、make_quiz({'lecture': 2}) の1回。
- 1つの質問での LLM 呼び出し回数（`requests`）：
  LoRAとQLoRAの質問は requests=2（tool_calls=2）。
  確認問題の質問も requests=2（tool_calls=1）。
- 追加したツールと、docstring に書いた説明：
  make_quiz(lecture: int)。用語集から指定した回の用語を1つ選び、
  「○○の意味は？」という問題と答え（定義）を返す。
  docstring は「指定した回の用語から1つを選び、確認問題と答えを返す。
  『第2回の確認問題を出して』のように、復習用の問題を求められたときに使う。
  lecture は1始まりの回番号（整数）。」

## 宿題

- 取り組んだレベル：基礎
- やったこと：
  app/agent.py の INSTRUCTIONS から、次の1行だけを消した。
  「用語や講座に固有のことを答える前に、必ず search_glossary で用語集を確認する。」
  変更の前後で、同じ質問「LoRAとQLoRAの違いは？」を `--trace` 付きで実行して比べた。
  （比べたあとは、INSTRUCTIONS を元に戻した）
- 結果：
  | 項目 | 変更前 | 1行を消した後 |
  |---|---|---|
  | search_glossary の呼び出し | 2回（'LoRA'、'QLoRA'） | 2回（'LoRA'、'QLoRA'） |
  | requests / tool_calls | 2 / 2 | 2 / 2 |
  | input_tokens | 1368 | 1320 |
  検索の呼ばれ方・回数・引数は変わらなかった。input_tokens が48減ったのは、消した1行の分。
  回答の文面は、実行のたびに少し違った（変更前の2回でも、説明の切り口が違った）。
- 気づき・疑問：
  INSTRUCTIONS から「必ず検索する」を消しても、モデルは検索をやめなかった。
  search_glossary の docstring に「答える前に使うこと」と、同じ趣旨の指示があるからだと考えられる。
  ただし、docstring は変えていないので、これは推測で、確かめていない。
  確かめるなら、docstring の該当部分も消して、同じ質問で比べる必要がある。
  また、同じ質問でも回答の文面は毎回ぶれるので、回答の内容の違いは、
  1回の比較だけでは、変更の効果と判断できないと感じた。
